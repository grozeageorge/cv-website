# CV Website

This is a simple CV website designed to showcase personal and professional information in a clean and organized manner.
## Live Demo

You can view the live version of this website at [https://grozeageorge.netlify.app](https://grozeageorge.netlify.app).
## Features
- Personal details section
- Work experience
- Education background
- Skills and achievements
- Contact information

## Technologies Used
- HTML
- CSS

## How to Use
1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/cv-website.git
    ```
2. Open the `index.html` file in your browser to view the website.

## Customization
- Update the HTML file with your personal details.
- Modify the CSS file to change the design and layout.
- Add JavaScript for interactivity if needed.
